# 知识大乱斗 · 答题对战跳棋

> 单文件离线网页游戏：中国跳棋 + 答题对抗。**走到哪、答到哪**——真人之间隔子跳触发答题，赢了继续跳，输了原地停，先到对面者得名次分。
>
> 一个 HTML 文件即是全部：游戏逻辑、内置题库、内置名单、配图全部内嵌，**双击即玩、断网可玩、拷到任何电脑可玩**。

---

## 一、30 秒开玩

1. 双击 `知识大乱斗.html`（推荐 **Chrome / Edge**）。
2. 选人数开局（1-6 人，可真人/电脑混搭），排兵后进入棋局（每席一队，已选队伍后面自动禁选；队伍数不够时自动放开重复）。
3. 点己方棋子 → 点高亮格走子；真人跳过真人时触发答题，答对继续跳。

**进阶（可选）**：点顶部【连接游戏目录】选一个文件夹，游戏即可读写该文件夹里的名单和题库、自动保存每局积分。没有现成文件也没关系——换到空目录时页面会提示**生成示例文件**。

> 分发给别人：只拷 `最终\知识大乱斗.html` 一个文件即可（配图已内嵌）。详见 `最终\使用说明.txt`。

## 二、游戏规则

### 跳棋规则
- 六角星棋盘（每边 10 孔），**2-6 人局**，每方 6 子，六色：红、蓝、紫、绿、黄、橙。
- 相邻一步、隔子直跳、多子连跳均可；**寻路自动取最短路径**（能直跳不绕路，避免无谓的答题场次）。
- 己方 6 子全部进入正对面阵营即完成；结算按完成名次计分。
- 席位可混人类与电脑，电脑自动走子；3 人局时三方对面都是空营（座位红蓝紫）。

### 答题对抗（本作灵魂）
- **触发条件**：移动方是真人、被跳方也是真人、且被跳方未完赛。电脑走子不触发；1 真人局全程无答题属正常。
- **各就各位预备屏**：先看本次科目与双方信息（队名·宣言 / 姓名·积分），点【开始答题】才出题、60 秒倒计时才开始走（最后 10 秒变红闪动）。
- **得分**：答对方队 +1、个人 +0.5，移动方可继续跳；答错/超时则回合结束。
- **抽题**：优先抽移动方队员擅长科目的题，已用不重、用尽循环。
- 答完展示结算卡：正确答案 + 解析 + 双方得分明细。

### 名次与积分结算
- 走完全程弹结算窗：名次分明细（如 `第1名 A队 +6`、`第2名 A队 +1`），电脑席不计分。
- 已连接目录 → 积分**自动写回** `队伍与队员.csv`（文件被 Excel 占用时提示关闭后【重试保存】）。
- 未连接 → 可点【导出本局积分】下载 CSV。

## 三、数据文件

游戏目录（连接的那个文件夹）里放两个 CSV，全部支持**直接用 Excel 编辑**：

### `队伍与队员.csv`（两段式）
```csv
[队伍]
队伍名称,队伍宣言,队伍积分
A队,,0

[队员]
队伍名称,队员姓名,个人积分,擅长科目
A队,张某,0,
A队,王某,0,数学
```
- `#` 开头为注释行；擅长科目只能填九科之一，留空表示无擅长。

### `题库.csv`
```csv
科目,题干,选项A,选项B,选项C,选项D,答案,解析,配图
数学,一个三角形，a 边长 3，b 边长 4，它是一个什么样的三角形？,正三角形,锐角三角形,直角三角形,钝角三角形,C,3-4-5 满足勾股定理，是直角三角形,例题配图.png
```
- **九科**：语文、数学、外语、道法、常识、地理、历史、物理、生物。
- 第 9 列 `配图` 可选：填图片文件名（图片放同一目录）；找不到图时显示"配图缺失"，内置配图已内嵌不受影响。
- **编码**：UTF-8 和 Excel 另存的 ANSI/GBK 都能读（程序自动识别），中文不会乱码。
- 解析出错会精确到"第 N 行"并说明原因，改完重连即可。
- 缺文件时可一键**生成示例**（带"示例"标记，读文件时自动过滤：当场可见、之后不再显示、文件里留着当格式参考；示例队/示例队员/示例题**只在管理页展示，不进排兵与抽题**）。
