知识大乱斗（跳棋答题）单机版 · 使用说明
========================================

一、这是什么
  一个单文件离线小游戏：跳棋对战，走到哪答到哪，赢了继续走、输了原地停。
  所有题目、图片、逻辑全部内嵌在这一个 HTML 文件里，不需要联网、不需要安装。

二、怎么玩
  1. 把「知识大乱斗.html」这个文件拷到电脑上（U盘、微信传输都行）。
  2. 双击它，默认浏览器打开即可开玩。
  3. 推荐用 Chrome 或 Edge 浏览器打开，兼容性最好。

三、单文件说明
  - 只拷「知识大乱斗.html」这一个文件，游戏就完整可玩（配图已内嵌在文件里）。
  - 「例题配图.png」是原图留档，不拷也不影响运行；放在 html 旁边时会优先用它。

四、进阶：连接自己的题目和名单（需 Chrome/Edge）
  1. 新建一个文件夹，把「队伍与队员.csv」「题库.csv」放进去（没有的话，
     打开游戏后点【连接数据文件夹】选一个空文件夹，页面会提示
     「是否要生成示例文件」，点【生成示例】即可自动生成这两个文件）。
  2. 游戏里点【连接数据文件夹】，选中该文件夹。
  3. 之后游戏的对局积分会自动写回名单文件，题目和名单也可以直接在游戏里改。
  - CSV 文件可以直接用 Excel 编辑，另存为 CSV（不管 UTF-8 还是
     Excel 默认的 ANSI/GBK 编码）程序都能正常读取。

五、常见问题
  Q：双击打不开？A：右键文件 → 打开方式 → 选 Chrome / Edge。
  Q：题目配图显示"配图缺失"？A：只有题目里填了文件名但找不到图时才会，
     内置题目不受影响；自己出题时把图片放和 html 同一个文件夹并填文件名。
  Q：能改题目吗？A：连接数据文件夹后在游戏内改，或直接用 Excel 改 CSV。
